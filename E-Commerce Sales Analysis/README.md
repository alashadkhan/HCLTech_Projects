# E-Commerce Sales Analysis

A Python project that analyzes e-commerce sales data using Pandas.

## Project Goal

The goal of this project is to analyse the order history of an online shopping
company to understand customer behaviour: what people buy, how much they spend,
whether they return to shop again, and whether delivery or order problems are
connected with customer feedback.

The findings are used to help the company improve customer experience and
encourage repeat purchases.


## Files

- `ecommerce_data.csv` – Sample dataset with 30 orders
- `analysis.py` – Main analysis script (answers all 8 investigation questions)

## What It Answers

1. Total orders and total completed-order value and sales
2. Categories and cities contributing most to orders and sales
3. Proportion of customers placing more than one order
4. Average order value difference between customer groups
5. Rates of cancellation and return
6. Whether longer delivery durations appear with lower customer ratings
7. Customer segments with stronger repeat-purchase behaviour
8. Recommended actions to improve customer experience

## How to Run

```bash
pip install -r requirements.txt
python analysis.py
```
